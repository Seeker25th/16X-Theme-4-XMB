# 16X-Theme-4-XMB
![宣传图](https://github.com/Seeker25th/16X-Theme-4-XMB/blob/main/Promotional.png?raw=true)

16X Theme 4 XMB是一个适用于**RetroArch、Lakka**和**GameBox Pro**的自定义XMB主题图标

>Lakka是libretro发行的一个基于Retroarch制作的开源项目，功能跟Retroarch差不多，可以装在树莓派上<br>
>Gamebox Pro是小白工坊基于Retroarch开发的运行于HarmonyOS上的移植版本

目前已覆盖绝大部分菜单图标和绝大部分机型图标

以下是装备此风格的相关说明↓

## 用于XMB驱动界面
压缩包到手后，将`main icons`中的`png`文件夹解压到`素材文件夹（assets）/xmb/custom/`内

（没有就新建一个）

随后打开全能模拟器，去设置>界面>外观>图标主题选项内

选择“自定义”，就可以看到这些新鲜的像素图标啦！

## 可替代图标

在“`ALTs`”文件夹内有一些可用于替换的图标，包括另一个版本，地区变体版本、被丢弃的设计、旧版本图标等等……以及一些纯用来整活的图标……

要使用的话，可直接用这个图片换掉素材文件夹内对应图片
## 其他说明

此库不带字体，要什么字体自己去其他地方找去吧

# 16X-Theme-4-XMB
![宣传图](https://github.com/Seeker25th/16X-Theme-4-XMB/blob/main/Promotional.png?raw=true)

16X Theme 4 XMB是一个适用于**RetroArch、Lakka**和**GameBox Pro**的自定义XMB主题图标，所有图标均由来路不明的闲人绘制，均为16*16的像素图标，已覆盖绝大部分UI图标、主流机型列表图标、多数小众机型列表图标以及部分虚构机型列表图标

以下是装备此风格的相关说明：

## 用于<XMB>驱动界面
压缩包到手后，将`png`文件夹解压到`素材文件夹（assets）/xmb/custom/`内

随后打开全能模拟器，去设置>界面>外观>图标主题选项内

选择“自定义”，就可以看到这些新鲜的像素图标啦！这可是最不影响其他元素的办法

前提是……你使用的菜单驱动是XMB，子标题里已经提到了
### 常见问题
- 素材文件夹到底在哪啊？急！
  - 可以在设置>文件夹>素材那里确定位置！
- 没看到`custom`文件夹怎么办？急急！
  - 直接新建一个同名文件夹！
- GameBox Pro的素材文件夹在那啊？急急急！
  - 放在`/Download/org.xbstudio.gameboxpro（文件夹GameBox Pro）/GameBox/`里面了，那个叫`assets`的文件夹就是！

## 用于<OZONE>驱动界面
全能模拟器的Ozone界面理论上也支持自定义图标，不过会比较麻烦一点

压缩包到手后先用里面的`png`文件夹覆盖`素材文件夹（assets）/xmb/monochrome/`，因为在Ozone界面中，图标其实使用的是这里的图标

再将里面的`ozone`文件夹直接解压至素材文件夹（`assets`）内，合并，一定要合并！

压缩包里面的`ozone`文件夹里面，是侧边栏图标补丁，和左上角的图标补丁，如果不看这步骤，会发现左边侧边栏的一些图标没被替换，要留意一下

在Ozone装备这些图标时，建议与深色主题搭配，因为图标是彩色的，换成浅色主题是，文字是黑的，图标也会染成文字的颜色，看起来会很奇怪

## 用于<桌面菜单>
> 目前作者已知Windows上的全能模拟器有这个功能，因此此条目仅适用于Windows上的全能模拟器

全能模拟器桌面菜单的列表也使用了图标，主要使用了xmb的dot-art图标包

压缩包到手后用里面的`png`文件夹覆盖`素材文件夹（assets）/xmb/dot-art/`就行

## 可替代图标
在“`可根据喜好替换`”文件夹内有一些可用于替换的图标，包括另一个版本，地区变体版本、被丢弃的设计、旧版本图标等等……以及一些纯用来整活的图标……

要使用的话，可直接用这个图片换掉素材文件夹内对应图片

## 动态背景
这里还提供了与16X风格搭配时效果拔群的动态背景！选择合适的比例，并放到`素材文件夹（assets）/wallpapers/`内，指定对应的列表时自动替换成相应的背景
